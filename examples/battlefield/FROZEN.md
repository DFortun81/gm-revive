# Frozen (7 November 2026)

This copy of Battlefield (the 2013 `.gmk` plus its GML overrides) stopped changing on 7 November 2026.
It stays here as gm-revive's main test case for the converter.

The game itself was ejected to plain JavaScript (`python -m gm_revive eject`) and is developed on its own
in the Battlefield repository (github.com/DFortun81/Battlefield). New Battlefield features go there.
